# Análisis de anuncios de venta de coches

Esta aplicación web permite explorar un conjunto de datos de anuncios de venta 
de coches en EE. UU. Muestra un análisis exploratorio básico de los datos, 
incluyendo:

- Un histograma de la distribución del kilometraje (odometer) de los vehículos.
- Un gráfico de dispersión que compara el precio contra el kilometraje.

El usuario puede activar cada gráfico usando las casillas de verificación 
disponibles en la aplicación.

## Cómo ejecutar la app

1. Instala las dependencias: `pip install -r requirements.txt`
2. Ejecuta: `streamlit run app.py`
